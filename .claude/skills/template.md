# スキル名

ここに指示を書く。このファイルのベースネームがスラッシュコマンド名になる。
例: `my-skill.md` → `/my-skill`

## 基本的な書き方

- Claudeへの指示をそのまま書けばよい
- `$ARGUMENTS` でユーザーが渡した引数を受け取れる（例: `/my-skill foo bar`）

## 例: コミット生成スキル (commit.md)

```markdown
---
description: ステージ済みの変更をもとにコミットメッセージを生成してコミットする
---

git diffを確認し、変更の意図を一行で表すコミットメッセージを日本語で作成してコミットせよ。
```

## 例: 引数を受け取るスキル (greet.md)

```markdown
---
description: 指定した名前に挨拶する
---

$ARGUMENTS に向けて丁寧な挨拶文を書いてください。
```
